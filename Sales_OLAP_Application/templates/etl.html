💻 Developer CLI Administration & ETL Controls

Command-Line Interface

In accordance with strict security requirements, the user-facing administrative portal has been removed. Data Warehouse ETL operations, catalog imports, and schema migrations are executed via command-line tools:

1. Execute Full ETL Pipeline: python etl.py --run

Extracts from pharma_sales.csv, audits schemas, normalizes dates, flags expired inventory, and loads fact tables.

2. Check Data Warehouse Telemetry: python etl.py --status

Outputs row counts for sales, medicines, pharmacies, hospitals, weather observations, and last refresh timestamp.

3. Rebuild / Migrate Database Schema: python migrate_db.py

Initializes Star & Snowflake tables, indexes, RBAC accounts, and certified transplant centers.

4. Import Medicine Formulary Catalog: python import_catalog.py <catalog_file.csv>

Validates and imports legitimate pharmaceutical formulary records into dim_product.
